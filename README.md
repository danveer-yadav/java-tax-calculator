# Java Tax Calculator
This is a simple Java program that calculates tax based on income slabs.

## Features
- Income < 5 Lakh: No tax
- Income 5 to 10 Lakh: 20% tax
- Income > 10 Lakh: 30% tax

## How to Run
1. Download or clone this repository.
2. Run `Tax.java` in any Java IDE (Eclipse, VS Code, IntelliJ) or Terminal.
